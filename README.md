## `how my projects are wired`

Every project turns into the same shape. One source of truth. Everything else is a client.

<div align="center">

<img src="https://raw.githubusercontent.com/ShockRock2004/ShockRock2004/main/assets/pipeline.svg" alt="how my projects are wired" width="100%" />

</div>

And the loop that keeps producing it.

```mermaid
flowchart LR
    A["idea at 1am"] --> B["build the ugly version"]
    B --> C{"survives a<br/>real device?"}
    C -- no --> D["read the error properly"]
    D --> B
    C -- yes --> E["ship it"]
    E --> F["break it on purpose"]
    F --> G["write down what broke"]
    G --> A

    style A fill:#0B0F14,stroke:#22D3EE,color:#E6EDF3
    style B fill:#0B0F14,stroke:#38BDF8,color:#E6EDF3
```
